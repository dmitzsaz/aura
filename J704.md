# J704 / M5 fork

This fork preserves the tested `main` baseline
`553b566f69275ff4e46ee6542a7236fb80a333a2` and the local J704 changes.
Target: Mac17,2 / J704AP / T8142. This is a development snapshot.

- Reserve MTP firmware DRAM from the current boot's ADT rather than an old
  physical address. Optional AOP/AOP2 reservations validate complete ranges
  and update the FDT transactionally; they do not start the peripherals.
- Clear the additional runtime/BSS span of decompressed ARM64 payloads.
- `J704_NATIVE_DIAG` enables board-specific boot messages and retains a failed
  boot on the display/UART for diagnosis.

The Aura and U-Boot source combination was built and verified through direct
native boot on J704 with the v15 loader package. Current-boot ADT processing
and a matching board DT are required. Boot-specific DTBs, raw ADTs, Apple
firmware, calibration, captures and built boot payloads are not distributed
here. These code changes alone are not an installation image and do not
establish working J704 audio or camera support.

Companion sources: [U-Boot](https://github.com/dmitzsaz/u-boot),
[Linux](https://github.com/dmitzsaz/linux), [Mesa](https://github.com/dmitzsaz/mesa),
[AVD firmware](https://github.com/dmitzsaz/avd-fw).
